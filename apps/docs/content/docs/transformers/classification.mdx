Classify text into predefined categories using fine-tuned transformer models. Useful for sentiment analysis, content moderation, and topic detection.

<Callout type="info">
  For full API reference (`classify()`, `classifyMany()`, options, result types, and custom providers), see the [Core Classification](/docs/core/classification) guide.
</Callout>

<Callout type="info" title="See it in action">
  Try the [Sentiment Analyzer block](https://localmode.ai/blocks/text-insights/sentiment-analyzer) — it runs DistilBERT SST-2 sentiment on single inputs and large batches with throughput. Install it with `npx shadcn add @localmode/ui/blocks/text-insights/sentiment-analyzer`.
</Callout>

## Recommended Models

| Model | Size | Labels | Use Case |
|-------|------|--------|----------|
| `Xenova/distilbert-base-uncased-finetuned-sst-2-english` | ~67MB | POSITIVE/NEGATIVE | Sentiment analysis |
| `Xenova/twitter-roberta-base-sentiment-latest` | ~125MB | Positive/Neutral/Negative | Social media sentiment |
| `Xenova/toxic-bert` | ~110MB | Toxic/Non-toxic | Content moderation |

## Best Practices

<Callout type="tip" title="Classification Tips">
  1. **Choose task-specific models** — Sentiment models work best for sentiment, not topic detection
  2. **Check allScores** — Low confidence scores may indicate ambiguous input
  3. **Batch when possible** — `classifyMany()` is more efficient than multiple `classify()` calls
  4. **Cache the model** — Create the model instance once and reuse it
</Callout>
