# LocalMode

**LocalMode** is a modular, local-first AI engine for the browser. Run embeddings, vector search, RAG pipelines, LLM chat, agents, structured output, text classification, NER, translation, summarization, speech-to-text, text-to-speech, image captioning, object detection, image segmentation, OCR, document Q&A, multimodal search, hand/pose/face tracking, gesture recognition, language detection, and evaluation — all directly in the browser with zero server dependencies.

**15 packages. 11 live blocks. Zero cloud dependencies.**

<Callout type="info" title="Privacy by Default">
  All processing happens locally. No data ever leaves the user's device. Zero telemetry. Zero
  tracking. Built-in encryption, PII redaction, and differential privacy.
</Callout>

## Why LocalMode?

- **Privacy** — Data never leaves the device. No telemetry, no tracking, no network requests from core.
- **Offline** — Works without internet after model download. Automatic fallbacks for every capability.
- **Fast** — No network latency. WebGPU acceleration where available. Instant inference.
- **Free** — No API costs, no rate limits, unlimited usage.
- **Universal** — Works in Chrome, Edge, Firefox, and Safari. Adapts to device capabilities.
- **Interoperable** — Vercel AI SDK patterns. LangChain.js adapters. Import from Pinecone/ChromaDB.

### Semantic search with embeddings

```typescript
import { embed, embedMany, createVectorDB, chunk } from '@localmode/core';
import { transformers } from '@localmode/transformers';

// Create embedding model
const model = transformers.embedding('Xenova/bge-small-en-v1.5');

// Create vector database with typed metadata
const db = await createVectorDB<{ text: string }>({
  name: 'docs',
  dimensions: 384,
});

// Chunk and embed documents
const chunks = chunk(documentText, { size: 512, overlap: 50 });
const { embeddings } = await embedMany({
  model,
  values: chunks.map((c) => c.text),
});

// Store vectors
await db.addMany(
  chunks.map((c, i) => ({
    id: `chunk-${i}`,
    vector: embeddings[i],
    metadata: { text: c.text },
  }))
);

// Search
const { embedding: query } = await embed({ model, value: 'What is AI?' });
const results = await db.search(query, { k: 5 });
```

### LLM chat with streaming

Five providers implement the same `LanguageModel` interface — choose based on your needs:

```typescript
import { streamText } from '@localmode/core';
import { webllm } from '@localmode/webllm';

// Pick any provider — all share the same LanguageModel interface
const model = webllm.languageModel('Llama-3.2-1B-Instruct-q4f16_1-MLC');
// const model = wllama.languageModel('Llama-3.2-1B-Instruct-Q4_K_M');
// const model = transformers.languageModel('onnx-community/Qwen3-0.6B-ONNX');
// const model = chromeAI.languageModel(); // zero-download Gemini Nano (Chrome 138+)

const result = await streamText({
  model,
  prompt: 'Explain quantum computing simply',
  maxTokens: 500,
});

for await (const chunk of result.stream) {
  process.stdout.write(chunk.text);
}
```

### Structured output

```typescript
import { generateObject, jsonSchema } from '@localmode/core';
import { webllm } from '@localmode/webllm';
import { z } from 'zod';

const { object } = await generateObject({
  model: webllm.languageModel('Qwen3-1.7B-q4f16_1-MLC'),
  schema: jsonSchema(
    z.object({
      name: z.string(),
      age: z.number(),
      interests: z.array(z.string()),
    })
  ),
  prompt: 'Generate a profile for a software engineer named Alex',
});
```

## LLM Provider Comparison

| | WebLLM | Wllama | Transformers.js | LiteRT |
|-|--------|--------|--------------------|--------|
| **Runtime** | WebGPU | WASM (llama.cpp) + optional WebGPU | ONNX Runtime | Google LiteRT-LM (WebGPU + WASM) |
| **Models** | 32 curated (MLC) | 30 curated (25 language + 3 embedding + 2 reranker) + 160K+ GGUF | 16 ONNX (TJS v4) | 3 curated `.litertlm` — Gemma 4 E2B/E4B, Qwen3 0.6B |
| **Speed** | Fastest (GPU) | Good (CPU), faster with WebGPU | Good (CPU/GPU) | Good (early preview) |
| **Embeddings** | -- | 3 GGUF embedding models | Yes (many models) | -- |
| **Reranking** | -- | 2 reranker models | Yes (cross-encoder) | -- |
| **Structured Output** | Yes | Yes (JSON mode / grammar) | -- | -- |
| **Reasoning** | -- | Yes (thinking mode) | -- | -- |
| **Tool Calling** | Yes | Yes (via providerOptions) | -- | -- |
| **Vision** | Phi 3.5 Vision | Holo2 4B/8B, Gemma 4 E2B/E4B (mmprojUrl) | 5 vision variants (Qwen3.5 + Gemma 4) | — (text-only) |
| **Browser Support** | Chrome/Edge 113+, Safari 26+, Firefox 141+ | All modern browsers | All modern browsers (WebGPU optional) | Chrome/Edge 113+, Safari 26+, Firefox 141+ (WebGPU); Qwen3 0.6B also runs on CPU WASM |
| **Best For** | Maximum performance | Universal compatibility, model variety, reranking | Multi-task (embeddings + LLM in one package) | First-party Google runtime for Gemma |

A fifth option, [`@localmode/chrome-ai`](/docs/chrome-ai), provides **zero-download text generation** via Chrome's built-in Gemini Nano (Prompt API, Chrome 138+) — no model files to fetch, with `@localmode/transformers` as the recommended fallback for other browsers. For **image input in chat** (vision), use wllama (`mmprojUrl` models like Gemma 4), WebLLM (Phi 3.5 Vision), or Transformers.js (Qwen3.5 / Gemma 4 VLMs) — see the Vision row above.

## Architecture

LocalMode follows a **"zero-dependency core, thin provider wrappers"** architecture:

```text

│                          Your Application                             │
├───────────────────────────────────────────────────────────────────────┤
│                    @localmode/react  (61 hooks)                       │
├───────────────────────┬───────────────────────┬───────────────────────┤
│   @localmode/ai-sdk   │  @localmode/langchain │  @localmode/devtools  │
├───────────────────────┴───────────────────────┴───────────────────────┤
│                          @localmode/core                              │
│                                                                       │
│  VectorDB       Embeddings       Generation       Agents & Pipelines  │
│  (HNSW +        + Multimodal     + Structured     + Evaluation        │
│   WebGPU)                          Output         + Metrics           │
│                                                                       │
│  Security       Middleware        Import/Export    Model Cache        │
│  (DP, PII,      System                            + Registry          │
│   Crypto)                                                             │
├───────────────────────────────────────────────────────────────────────┤
│                        Provider Packages                              │
│                                                                       │
│  @localmode/transformers    HF Transformers.js       26 factories     │
│  @localmode/webllm          WebGPU                      32 models     │
│  @localmode/wllama          llama.cpp WASM           160K+ models     │
│  @localmode/litert          Google LiteRT-LM        .litertlm models  │

└───────────────────────────────────────────────────────────────────────┘
```

## Browser Compatibility

| Browser     | WebGPU  | WASM | IndexedDB | Workers | Chrome AI |
| ----------- | ------- | ---- | --------- | ------- | --------- |
| Chrome 138+ | Yes     | Yes  | Yes       | Yes     | Yes       |
| Edge 138+   | Yes     | Yes  | Yes       | Yes     | Yes       |
| Firefox 75+ | Nightly | Yes  | Yes       | Yes     | No        |
| Safari 26+  | Yes     | Yes  | Yes       | Partial | No        |

<Callout type="warn" title="Platform Notes">
  - **Chrome AI**: Zero-download inference via Gemini Nano (fallback to Transformers.js)
  - **WebGPU**: 3-5x faster inference (fallback to WASM)
  - **Safari/iOS**: Private browsing blocks IndexedDB — use `MemoryStorage` fallback
  - **Firefox**: WebGPU only in Nightly — WASM fallback is automatic
  - **SharedArrayBuffer**: Requires cross-origin isolation for some features
</Callout>
